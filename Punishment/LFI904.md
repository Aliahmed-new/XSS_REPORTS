
## Title
Local File Inclusion (LFI) via filejpg1 Parameter

## Vulnerability Type
LFI

## Summary
The application has a File feature and the images are loaded using file parameter by viewing the page source you will see the  link https://kzlabs.com/904.php?file=cat1.jpg  and by the adding the below payload  the server goes and fetches it. 

## Vulnerable Endpoint

```
https://kzlabs.com/904.php?file=cat1.jpg
```

## Steps to Reproduce

1.Open the following URL
```
http://kzlabs.in/904.php
```
2.Enter Ctrl+U to view the page source 

3.Turn on Intercept in Burp and click the link  — to capture the request

4.Send the request to Intruder

5.Add the postion next to file parameter

6.Copy the payloads and paste it in the payloads section 

7.Click on start attack 

8.You will notice the repsonse 200ok

9.The response comes back with the full contents of the server's /etc/passwd file showing all system user accounts


## Payload Used
```
../../../../etc/passwd
```

## Impact
- Full account takeover is possible if configuration files containing database credentials or API keys are read 
- Attacker can read sensitive internal files from the server such as /etc/passwd, /etc/hosts, configuration files and potentially private keys
  

## Remediation
1. Only allow https:// and http:// protocols and block everything else like file://, gopher://, ftp:// completely
2. Block requests to internal IP ranges like 127.0.0.1, 169.254.x.x, and 10.x.x.x so the server cant be used to probe internal services
3. Never return the raw response from a fetched URL back to the user and use cookie attribute
4. Validate and whitelist URLs on the server side
